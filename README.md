# 鲁班零号 / Luban Zero

> **私有项目 / Private project**

## 中文简介

鲁班零号（luban0）是一个以约 2B 语言核心起步的本地 AI 原型。项目探索前端快速决策、本地模型、后端 API 教师，以及可学习、增长和休眠的内部神经模块；暂时不用的冷权重可保存到硬盘。

“持续成长”是工程愿景，不代表已经证明无限能力增长。项目资料、研究记录和模型文件仅供项目成员使用，不作为开源项目发布。

## English

Luban Zero (luban0) is a private local AI prototype starting from an approximately 2B language core. It explores a fast decision layer, a local model, a backend API teacher, and internal neural modules that can learn, grow, and sleep; cold weights can be persisted to disk when they are not active.

“Continuous growth” is an engineering goal, not a claim of proven unlimited capability. Source materials, research records, and model files are restricted to project members and are not published as open source.

## 项目状态 / Project status

本仓库目前用于项目介绍与协作入口。实现、研究证据和内部流程会按阶段整理后再加入。

This repository currently serves as the project introduction and collaboration entry point. Implementation, research evidence, and internal workflows will be added in organized stages.
